# Strings vs Slices

The `string` data types, which is provided by Rust's standard library rather than coded into the core language, is a **growable**, **mutable**, **owned**, **UTF-8 encoded** string type. 

When Rustaceans refer to "strings" in Rust, they might be referring to either the `String` or the string slice `&str` types, not just one of those types. 

---

## What are Slices?

_Slices_ let you reference a **contiguous sequence of elements** in a collection rather than the whole collection. A slice is a kind of _reference_, so it does not have **ownership**.

---

## 1. Creating a string:
   ```rust
   fn main() {
     let name = String::from("Tushar");
     println!("name is {}", name);
   }
   ```
   
## 2. Mutating a string:
   ```rust
   fn main(){
     let mut name = String::from("Tushar");
     name.push_str(" Pamnani");
     println!("name is {}");
   }
   ```
   
## 3. Deleting from a string:
   ```rust
   fn main(){
     let muyt name = String::from("Tushar");
     name.push_str(" Pamnani");
     println!("name is{}, name");
     name.replace_range(6..name.len(), ""); // everything from character 6 till the end will be replaced to ""
     println!("name is {}, name");
   }
   ```

## Q: Write a function that takes a string as an input and returns the first word from it.

### Approach #1 - Return a new string

```rust
fn main(){
  let name = String::from("hello world"); // the original string
  let ans = first_word(str: name);
  println!("ans is {}");
}

fn first_word(str: String) -> String {
  let mut ans = String::from(""); // a new string that is being returned 
  for i in str.chars() {
    if i == ' ' {
      break;
    }
    ans.push_str(&i.to_string()); // adding the first word to the new string
  }
  return ans;
}
```

#### Problem: 
1. We take up double the memory
2. If the `name` string gets `cleared`, `ans` still has `hello` as the value in it.

What we want is a `view` into the original string and not copy it over

---

### A basic walk thorugh before jumping to approach 2
```rust
fn main() {
    let mut word = String::from("hello world");
    let word2 = &word[0..5];

    // word.clear(); // ❌ Error: cannot borrow `word` as mutable because it is also borrowed as immutable

    println!("{}", word2);
}

```
--- 

### Approach #2:
```rust
fn main() {
  let mut name = String::from("hello world");
  // ans = &name[0..index], ans ois an immutable reference to name
  let ans = first_word(str: &name);
  println!("ans is {}");
}

fn first_word(str: &String) -> &str {
  let mut space_index = 0;
  for i in str.chars() {
    if i == ' ' {
      break;
    }
    space_index += 1;
  }
  return &str[0..space_index];
}
```

## Some commonly used String Variants (there are actually much more)

```rust
fn main() {
  let name = String::from("hello world"); // String data type
  let string_slice = &name; // has  aview into the original string/ is a reference
  let string_literal = "hello"; // literal is also an &str but it points directly to an address in the binary (type still stays &str)
}
```

## Slices can also be applied to other collections like vectors/arrays

```rust
fn main() {
  let arr = [1, 2, 3];
  println!("{:?}", &arr[[0..1]);
}
```
